# Human Basis

Monorepo for **Basis** — an independent research lab building the infrastructure substrate for connecting many human-like neural nodes into a shared real-time experience.

First project: **Basis Nexus**.

## Layout

```
humanbasis/
  site/     Public landing page (served by GitHub Pages)
  stack/    Basis Nexus stack code (brain, snp, locus, fabric, trace)
```

## Landing page

The `site/` folder is a static site (HTML + CSS, no build step) hosted free on GitHub Pages.
